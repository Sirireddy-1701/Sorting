## 📌 About The Project

Sorting Algorithm Visualizer is an interactive web-based tool designed to help students and developers understand how sorting algorithms work step by step. Built using pure HTML, CSS, and JavaScript with no frameworks or dependencies — it runs directly in any browser without any installation or setup required.

The primary goal of this project is to make abstract sorting concepts visual and easy to understand. Instead of just reading about how Bubble Sort or Quick Sort works, users can watch each comparison and swap happen in real time, one step at a time.

---

## ✨ Features

- ✅ **5 Sorting Algorithms** — Bubble, Selection, Insertion, Merge, Quick Sort
- ✅ **Custom Array Input** — Enter your own numbers or generate a random array
- ✅ **Step-by-Step Control** — Next and Previous buttons to go through each step manually
- ✅ **Play / Pause** — Automatic animation with a single click
- ✅ **Animation Speed Control** — Slider from slow to fast (1× to 5×)
- ✅ **Color-Coded Bars** — See comparing, swapping, sorted, and pivot elements clearly
- ✅ **Time Complexity Panel** — Best, average, worst case, space complexity & stability info
- ✅ **Responsive Design** — Works on desktop and mobile browsers
- ✅ **No Dependencies** — Pure HTML, CSS, JavaScript. No install needed.

## 🎨 Color Guide

| Color | Meaning |
|-------|---------|
| 🟣 Purple | Default / unsorted |
| 🔵 Blue | Being compared |
| 🔴 Red / Orange | Being swapped |
| 🟡 Amber | Pivot / current minimum |
| 🟢 Green | Sorted / final position |

## 📊 Algorithms Covered

| Algorithm | Best Case | Average Case | Worst Case | Space | Stable |
|-----------|-----------|--------------|------------|-------|--------|
| Bubble Sort | O(n) | O(n²) | O(n²) | O(1) | ✅ Yes |
| Selection Sort | O(n²) | O(n²) | O(n²) | O(1) | ❌ No |
| Insertion Sort | O(n) | O(n²) | O(n²) | O(1) | ✅ Yes |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) | O(n) | ✅ Yes |
| Quick Sort | O(n log n) | O(n log n) | O(n²) | O(log n) | ❌ No |

## 🚀 How To Run

### Option 1 — Direct (Easiest)
1. Download the `index.html` file
2. Double-click it
3. It opens directly in your browser ✅

### Option 2 — Local Server (Mac/Linux)
```bash
# Navigate to the project folder
cd path/to/project

# Start a local server
python3 -m http.server 8080

# Open in browser
http://localhost:8080
```

### Option 3 — Clone from GitHub
```bash
git clone https://github.com/your-username/sorting-visualizer.git
cd sorting-visualizer
open index.html
```
